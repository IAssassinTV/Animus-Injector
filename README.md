# Claudia

This is a mini launcher for multiplayer mode of Assassin's Creed Brotherhood.

## Features

- Redirects from Ubisoft servers to AnimusNetwork's
- Fixes modern controllers by enforcing Xinput (say goodbye to x360ce!)
- Fixes CPU affinity
- Enforces PunkBuster to be disabled
- Supports Digital (Steam/Uplay) and Retail (1.03 WW/CZ/RU)

## Installation
- Grab the latest release from the [releases page](https://github.com/IAssassinTV/Claudia/releases)
- Extract the contents of the archive in to the the game folder. (e.g. "**steamapps\common\Assassins Creed Brotherhood**" for Steam).

## Configuration
- See **claudia.ini**.
